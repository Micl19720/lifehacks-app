# «Лайфхаки для жизни» — приложение для RuStore

Это готовый Android-проект. Он собирается автоматически на **GitHub Actions** (бесплатно, без твоего компьютера).

---

## Шаг 1. Завести GitHub (бесплатно)
1. Открой **github.com** в браузере.
2. Нажми **Sign up** → введи почту, придумай пароль, подтверди.
3. Это бесплатно.

## Шаг 2. Создать репозиторий
1. Войди в GitHub → нажми **«+»** → **New repository**.
2. Название: `lifehacks-app`.
3. Отметь **Private** (закрытый) — чтобы не светить.
4. Нажми **Create repository**.

## Шаг 3. Загрузить файлы проекта
1. В репозитории нажми **Add file → Upload files**.
2. Загрузи **все файлы и папки** из папки `app_project/` (settings.gradle, build.gradle, app/, .github/, gradle.properties).
3. Внизу нажми **Commit changes**.

> ⚠️ Не забудь папку `.github` (она с точкой в начале) — там workflow сборки.

## Шаг 4. Сборка APK (автоматически)
1. Перейди в репозиторий → вкладка **Actions**.
2. Должна запуститься сборка **Build APK** (или нажми **Run workflow**).
3. Подожди 2–4 минуты — сборка идёт сама.
4. Когда появится **зелёная галочка** — нажми на сборку → внизу блок **Artifacts** → скачай **apk-release**.

В архиве будут:
- `app-release.apk` — готовое приложение.
- `release.jks` — ключ подписи (**сохрани его!** нужен для обновлений приложения).

## Шаг 5. Аккаунт разработчика RuStore (бесплатно)
1. Открой **rustore.ru** → вверху **«Разработчикам»** → **«Консоль разработчика»**.
2. Зарегистрируйся через VK ID / почту.
3. Создай **«Профиль разработчика»** — укажи данные.

## Шаг 6. Опубликовать приложение
1. В консоли RuStore → **«Создать приложение»**.
2. Заполни: название **«Лайфхаки для жизни»**, описание, категорию.
3. Загрузи **app-release.apk**.
4. Добавь **скриншоты** (можно сделать с телефона: установи APK и сделай 2–3 скрина).
5. Иконка — уже встроена.
6. Отправь на модерацию.

## Шаг 7. Монетизация (реклама)
1. Когда приложение одобрят и начнут скачивать.
2. В консоли RuStore → раздел **«Монетизация»** → подключи **RuStore Ads**.
3. Получаешь деньги за показы рекламы.

## 📢 AdMob — подключить свою рекламу (после одобрения)
В проекте уже встроен **AdMob** (баннер внизу экрана). Пока стоит **тестовый** рекламный ID (Google тестовый). Когда создашь свой аккаунт — замени.

1. Создай аккаунт на **admob.google.com**.
2. Добавь приложение → получи **App ID** (вида `ca-app-pub-XXXX~YYYY`).
3. Создай **баннер** → получи **Ad Unit ID** (вида `ca-app-pub-XXXX/ZZZZ`).
4. Замени в **2 файлах**:
   - `AndroidManifest.xml` → строка `android:value="ca-app-pub-...~..."` → твой **App ID**.
   - `app/src/main/res/layout/activity_main.xml` → `ads:adUnitId="ca-app-pub-.../..."` → твой **Ad Unit ID**.
5. **Важно:** до одобрения AdMob оставь тестовые ID — они показывают тестовую рекламу и не блокируют модерацию.

## 📸 Скриншоты для RuStore (готовы)
Готовые яркие скриншоты лежат в папке **`screenshots/`** (1080×1920):

Загрузи их в RuStore при публикации (поле «Скриншоты»).
